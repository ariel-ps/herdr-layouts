# Security Policy

## Supported versions

Security fixes are applied to the latest release and the current `main` branch.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/ariel-ps/herdr-layouts/security/advisories/new). Include the affected version, reproduction steps, impact, and any suggested mitigation.

Do not disclose a vulnerability publicly until a fix is available. You can expect an initial response within seven days.
